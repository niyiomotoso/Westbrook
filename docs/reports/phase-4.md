# Phase 4 report — install and 7-day trial

Status: ready for the owner. Everything that can be done without the
physical tablets is done and tested; this phase is the on-site part.

What is ready:
- The wall and back office are live on the internet, on free services,
  with automatic updates on every change.
- A step-by-step tablet guide is in docs/RUNBOOK.md: charger, "stay awake",
  install the app from Chrome, pick the position, pin the screen. About
  five minutes per tablet.
- The back office Screens page shows each tablet's health from anywhere.

For the owner to do:
1. Set up the three tablets side by side following the runbook.
2. Film the three screens changing together once — they should move within
   a blink of each other (0.3 seconds).
3. Upload the real room and place photos, the logo, the Wi-Fi details, and
   the real prices.
4. Run the 7-day trial with the simple glitch log described in the runbook,
   then share the log.

One honest limitation to know: after a power cut the tablets restart but
the app waits for one tap on its icon (web apps cannot start themselves).
The free Fully Kiosk app, covered in the runbook, removes even that tap if
wanted.
