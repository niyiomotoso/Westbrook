# Phase 4 report — install and 7-day trial

Status: ready for the owner. Everything buildable without the physical
tablets is done and tested; this phase is the on-site part.

Ready now: the wall and back office are live on free services with
automatic updates, a step-by-step tablet guide in docs/RUNBOOK.md (about
five minutes per tablet), and a Screens page showing each tablet's health
from anywhere.

For the owner to do:
1. Set up the three tablets following the runbook, side by side.
2. Film the three screens changing together once (within 0.3 seconds).
3. Upload the real photos, logo, Wi-Fi details, and prices.
4. Run the 7-day trial with the runbook's glitch log, then share it.

One honest limitation: after a power cut the app waits for one tap on its
icon (web apps cannot start themselves). The free Fully Kiosk app in the
runbook removes even that tap if wanted.
